# Expense Tracker

**Автор:** Рукият Дзамихова

## Описание программы

Приложение для отслеживания личных расходов с графическим интерфейсом. Позволяет:
* Добавлять расходы с указанием суммы, категории и даты
* Фильтровать записи по категории и дате
* Подсчитывать общую сумму расходов за выбранный период
* Сохранять данные в JSON-файл
* Загружать данные при запуске приложения

## Технологии

* **Python 3.x** — основной язык программирования
* **Tkinter** — библиотека для создания графического интерфейса
* **JSON** — формат хранения данных
* **Git** — система контроля версий

## Как использовать

1. Убедитесь, что у вас установлен Python 3.6+
2. Скачайте или клонируйте этот репозиторий
3. Запустите файл `main.py`:
   ```bash
   python main.py
4. Приложение откроется в новом окне

### Интерфейс
* **Поля ввода:**
   * Сумма — введите положительное число
   * Категория — выберите из выпадающего списка
   * Дата — укажите в формате ГГГГ-ММ-ДД (по умолчанию — текущая дата)
* **Кнопка «Добавить расход»** — добавляет запись в таблицу
* **Таблица** — отображает все добавленные расходы
* **Фильтры:**
   * По категории — выберите категорию из выпадающего списка
   * По дате — введите дату в формате ГГГГ-ММ-ДД
* **Подсчёт суммы за период:**
   * Введите период в формате «ГГГГ-ММ-ДД - ГГГГ-ММ-ДД»
   * Нажмите «Посчитать сумму за период» — результат отобразится внизу

## Примеры использования
### **Тест 1: Добавление расхода**
1. Введите сумму: 1500
2. Выберите категорию: «Еда»
3. Оставьте дату по умолчанию
4. Нажмите «Добавить расход»
5. Запись должна появиться в таблице

### **Тест 2: Фильтрация по категории**
1. Добавьте несколько записей с разными категориями
2. В фильтре по категории выберите «Транспорт»
3. В таблице должны остаться только записи с категорией «Транспорт»

### **Тест 3: Подсчёт суммы за период**
1. Добавьте записи с датами за разные дни
2. Введите период: 2024-01-01 - 2024-12-31
3. Нажмите «Посчитать сумму за период»
4. Должна отобразиться общая сумма за указанный год

## Сохранение данных
Все данные автоматически сохраняются в файл expenses.json в папке проекта. При следующем запуске приложения данные загружаются из этого файла.
